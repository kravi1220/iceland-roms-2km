    Methodology

    The Iceland 2 km ROMS daily-average output is colocated with Argo float profiles at the nearest ocean grid cell and closest daily model record in time; floats farther than 50 km from any model grid cell are excluded.

    Data source

    • Argo float profiles (temperature, salinity, pressure): Argo Program, obtained via the Argo Global Data Assembly Centres (Ifremer GDAC). Argo data are collected and made freely available by the International Argo Program and the national programs that contribute to it.
    • Citation: Argo (2000). Argo float data and metadata from Global Data Assembly Centre (Argo GDAC). SEANOE. doi:10.17882/42182
