About the Model

A ROMS (Regional Ocean Modeling System) configuration covering the waters around Iceland at roughly 2 km horizontal resolution.

~2 km
Horizontal resolution
602 × 652
Grid points (xi × eta)
10–3827 m

Longitude range
HAFRO
Institution

The domain spans the Iceland Sea, Denmark Strait, and the Irminger Sea and Iceland–Faroe shelf regions, using ROMS terrain-following (sigma) vertical coordinates. The grid was built at the Icelandic Marine and Freshwater Research Institute (Hafrannsóknastofnun, HAFRO).

Rendered directly from the model grid (iceland2km_grid.nc: h, mask_rho, lon_rho/lat_rho) — pan and zoom to explore the domain.

ROMS

ROMS is a free-surface, terrain-following, primitive-equation community ocean model used widely for coastal and regional ocean simulation. See myroms.org for the model source and documentation.

Data & code

This site currently hosts validation figures comparing the model against independent observations (Argo floats, moorings). See the GitHub repository for the site source and the scripts used to generate these comparisons.
